PROCO Demostración

Aplicación completa de simulación para Windows11 Intel/AMD64bits.

Preparación inicial, con internet

  1. Instala PROCO con el asistente. El acceso directo se llama PROCO Demostración.
  2. Si el portátil no tiene Docker Desktop, abre el enlace de preparación del panel. Instálalo desde su página oficial y acepta sus condiciones según la organización. Usar contenedores Linux. Si pide habilitar WSL/virtualización o reiniciar, solicita apoyo de TI. No se requiere instalar Java o PostgreSQL por separado.
  3. Abre Docker Desktop y espera a que el motor esté listo. Abre PROCO y pulsa Iniciar demostración. La primera carga de los componentes incluidos puede tardar varios minutos.
  4. El navegador se abrirá cuando la aplicación esté lista. Elige almacen, contraseña Simulacion123!. El manual explica los demás roles.
  5. Desconecta internet y comprueba que puedes detener, volver a iniciar, cambiar de usuario y consultar el manual antes de la presentación.

Durante la demostración

  • Iniciar demostración: abre la sesión seleccionada, conservando los datos.
  • Manual: abre la guía HTML con capturas, búsqueda y recorridos por rol; no necesita que Docker esté iniciado.
  • Detener: detiene solo la sesión seleccionada, sin borrar datos. Cerrar el navegador o el panel no detiene los contenedores.
  • Nueva demostración: detiene la seleccionada y crea otra desde los cinco lotes iniciales. La anterior queda en la lista. No precarga montajes autorizados con fechas de vencimiento.
  • Diagnóstico: guarda un archivo para soporte si algo no inicia. No cambies configuraciones avanzadas durante la presentación.
Solo simulación. No hay movimientos físicos, máquinas, ERP ni comunicaciones reales con proveedores. Los datos se conservan en Docker al desinstalar el panel; eliminar Docker o sus volúmenes sí puede perderlos. No elimines recursos desde Docker Desktop para reiniciar una demostración.

Antes de presentarlo

Se entregan cinco lotes base: dos en recepción y tres liberados/disponibles. Los ejercicios avanzados se realizan con los roles y pasos del manual, creando lotes propios para evitar que una NC afecte otros casos. Una autorización vencida no se renueva automáticamente: crear otra solicitud cuando corresponda. No confundir pruebas técnicas con aceptación del procedimiento por PROCO.

Si Windows identifica editor no reconocido, verifica el origen y el SHA-256 del paquete con el responsable de TI. Esta edición aún no lleva firma corporativa; no cambies políticas de seguridad ni desactives protecciones para instalarla.
